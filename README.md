# Designer tool
This tool is created for game designing. This tool can help for creating GDD (game design document). <br>
## Current features
Partially supports users.
## Planned features
- Mood board
- UI design tool
- documenting tool
- Calender
- Notes

## Installation
 Create .env file on root and write next lines on that file. Change value to match your postgresql database.  
 > DB_USERNAME="postgres" <br>
 > DB_URL="jdbc:postgresql://localhost:5432/design_tool" <br>
 > DB_PASSWORD="your password" <br>
